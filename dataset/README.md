# Dataset

The actual raw dataset is intentionally not stored in GitHub because it is about 280 MB.

Use:

```bash
python download_dataset.py
python prepare_classification_dataset.py
```

Source dataset:
https://github.com/SakhawatHossain/chem-lab-equipment-recognition

Figshare ZIP:
https://figshare.com/ndownloader/files/44682395

The project converts the source YOLO object-detection dataset into cropped class folders for the required image-classification task.
